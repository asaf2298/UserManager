--- מפרט קישוריות לתוסף Stremio Israel (LiveTV) ---

1. נתיבי Endpoint (עבור ה-Proxy שלך):
   - סדרות וערוצי טלוויזיה: /meta/series/{id}.json
   - סרטים: /meta/movie/{id}.json
   (שים לב: למרות שבתוך ה-JSON השדה type הוא "tv", ה-SDK משתמש בנתיב "series")

2. שם התוסף (מניפסט): LiveTV Israel
   שם קובץ השרת המקורי: addon.js

3. דרישות Headers (מומלץ להעביר מהבקשה המקורית):
   - User-Agent (חשוב להעברת המזהה של אפליקציית סטרימיו)
   - X-Forwarded-For (לשמירה על ה-IP של הלקוח)
   - Accept-Encoding: gzip (מומלץ לתמיכה בדאטה כבד)

4. מבנה אובייקט ה-Meta להחזרה (JSON Response):
{
  "meta": {
    "id": "{id}",
    "type": "tv",
    "name": "{שם הערוץ/סדרה}",
    "poster": "{URL_לתמונה}",
    "background": "{URL_לרקע}",
    "description": "🔴 עכשיו: {תוכנית_נוכחית} [שעה]\n📝 תקציר: {טקסט}...\n\n⏭️ בהמשך:\n• [שעה] {תוכנית_באה}\n──────────────────────────────",
    "genres": ["ערוצי ישראל"],
    "videos": []
  }
}

הערות חשובות לפרוקסי:
- השדה "videos" חייב להישאר רשימה ריקה [] עבור ערוצי לייב כדי שסטרימיו יציג כפתור "Play" בודד.
- וודא שהפרוקסי שלך מעביר את ה-ID בדיוק כפי שהוא ללא Double Encoding.
- אין דרישות אבטחה מיוחדות (תעודות/Headers מיוחדים) - התוסף מגיב לבקשות סטנדרטיות.
